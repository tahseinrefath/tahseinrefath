# ⭐ Featured Projects

## 🍽️ 01. Nehru Canteen Management System

> **A web-based college canteen ordering and token management system**

Nehru Canteen is a full-stack web application designed to make the college canteen ordering process faster and more organized.

Students can view available food items, place orders, complete payments, receive a token, and track their order status without standing in a long queue.

### ✨ Key Features

- 🍔 Food menu with categories
- 🛒 Online food ordering
- 🎫 Token-based ordering system
- 💳 Payment workflow
- 📊 Order status tracking
- 👨‍💼 Admin dashboard
- 🍳 Food preparation management
- 🔔 Order and delivery notifications
- ⏱️ Reduced waiting time at the canteen

### 🧰 Technologies

`HTML` `CSS` `JavaScript` `Python` `Flask` `MySQL` `SQLAlchemy`

## 🔎 02. Lost & Found Management System

> **A digital platform for reporting and recovering lost items**

A web-based Lost & Found system designed to help students report lost belongings and connect them with people who may have found those items.

The system provides a structured way to submit item details, search reported items, and manage lost-and-found records.

### ✨ Key Features

- 📢 Report lost items
- 📦 Report found items
- 🔍 Search and browse items
- 📝 Item details and descriptions
- 👤 User-based management
- 📋 Organized lost & found records
- 🤝 Helps connect owners with found items

### 🧰 Technologies

`HTML` `CSS` `JavaScript` `Python` `Flask` `MySQL`
